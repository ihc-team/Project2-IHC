# Task 02 — Autenticación y rutas protegidas

## Tarea 1

### Funcionalidades obligatorias

- [x] Registro de una cuenta nueva.
- [x] Inicio de sesión.
- [x] Cierre de sesión.
- [x] Recuperación y cambio de contraseña (no se exige enviar un correo real).
- [x] Sesión conservada al recargar la aplicación.
- [x] Una ruta pública al recargar la aplicación.
- [x] Una ruta privada que exija sesión y redirija al login cuando no exista.
- [x] Validar persona autenticada dentro de la ruta privada.

### Qué deben entregar

- Repositorio con el código ejecutable.
- `README.md` con el comando exacto para iniciarlo.
- Commits que permitan reconocer el avance.

### Opcionales

- `docs/task-01-access.md` con modalidad, decisiones y archivos principales.
